# qBittorrent-WebUI-Selected-Count-and-Total-Size
Select the desired torrents, and their total size will be displayed in a dedicated panel located in the bottom-right corner. The value updates automatically.
Calculate qBittorrent Selected Torrents Total Size WebUI

Select the desired torrents, and their total size will be displayed in a dedicated panel located in the bottom-right corner. The value updates automatically.

This script was created with the assistance of Copilot specifically for version 5.2.0, as a similar script by @viktor88 does not function on this version; compatibility with earlier versions is not guaranteed. Please note: By default, the script is configured for the WebUI address `http://localhost:8080/`. If your WebUI is accessible at a different address, be sure to modify the script code to reflect your specific URL.

Currently, the script has been adapted for English and Russian languages ​​only. Please submit any suggestions via the Feedback section or to t.me/thetrtk.
